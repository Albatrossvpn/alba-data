Steps

Most current distributions with a desktop. You need an Albatross account: a username and a password, nothing else. Buy one in our Telegram bot, or on your account page with USDT.

  1. Download the file for your computer: x86-64 for most PCs and laptops, ARM64 for ARM computers. It is a tar.gz archive, Albatross-<version>-linux-x86_64.tar.gz or -linux-arm64.tar.gz.
  2. Unpack it: right-click it and choose Extract here, or in a terminal tar xzf and the file's name. You get a folder named Albatross; move it wherever you like, for example your home folder.
  3. Open the folder and run albatross: double-click it (in some file managers, right-click and Run as a Program), or in a terminal in that folder, ./albatross.
  4. To have Albatross in your applications menu, run ./install.sh once in the same folder. Run it again if you move the folder.
  5. The window opens in your browser. Sign in with your username and password and press the big button.

To start Albatross again, open it from the menu or run albatross again: it brings back the window of the copy that is already running. Before you delete the folder, turn off Start with the system in the app's settings, or run ./install.sh --remove.

Proxy mode

On Linux, Albatross works in proxy mode: it sets the system proxy of GNOME and KDE (Ubuntu, Debian, Fedora, Mint and most desktops), and browsers and apps that use it go through Albatross. When you disconnect or quit, the proxy you had before comes back, even if the app was closed by force. Protect the whole device is not available on Linux yet.

  • An app that ignores the system proxy can be pointed at Albatross by hand. In Settings, turn on Share with devices: a card shows an automatic setup address with a Copy button, and the two values to enter by hand.
  • In Firefox: Settings, Network settings, Automatic proxy configuration URL, and paste the address.
  • Do not run another VPN at the same time.
